Sao chép vào công cụ API cá nhân. Không đưa token vào URL, Git hoặc ảnh chụp màn hình. Khi nghi ngờ lộ, nhờ Admin thu hồi ngay.





Đường dẫn API và nguyên tắc sử dụng


Header Authorization: Bearer <token>. Chỉ dùng HTTPS khi truy cập qua mạng.


  • GET /api/internal/operations/queues — hàng đợi.
  • GET /api/internal/operations/tracking?codes=UTE123,UTE456 — tra cứu.
  • GET /api/internal/admin/access?page=0 — chỉ Admin.
